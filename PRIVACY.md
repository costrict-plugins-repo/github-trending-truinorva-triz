# Privacy Policy — Truinorva TRIZ Plugin for Claude

*Last updated: 10 May 2026*

This privacy policy describes how the **Truinorva TRIZ** plugin (the "Plugin") handles data. It applies to the Plugin only, not to other Truinorva GmbH services.

## What the Plugin is

Truinorva TRIZ is a collection of 26 instructional skills (Markdown files with TRIZ methodology guidance) that run inside Anthropic's Claude products (Claude.ai, Claude Code, Claude Cowork, and the Claude API).

The Plugin contains:

- Static Markdown instructions (`SKILL.md` files)
- Static reference materials (PDFs, text files, images) used by some skills

The Plugin does **not** contain:

- Executable code that connects to external services
- Telemetry or analytics
- Model Context Protocol (MCP) servers
- Network endpoints of any kind
- Cookies, web trackers, or device identifiers

## Data we collect

**None.** The Plugin itself does not collect, store, transmit, or share any personal data, prompts, conversation content, or usage information. Truinorva GmbH has no visibility into who uses the Plugin or how.

## Data processing during use

When you use the Plugin, your prompts and Claude's responses are processed by Anthropic under Anthropic's Privacy Policy: <https://www.anthropic.com/legal/privacy>.

Truinorva GmbH does not receive, observe, log, or otherwise have access to any of this data.

## Third-party data sharing

The Plugin does not share data with any third party, because it does not collect or process data in the first place.

## Cookies and tracking

The Plugin has no web component and uses no cookies, pixels, fingerprinting, or other tracking technologies.

## Children's privacy

The Plugin is intended for professional use in R&D, product, innovation, and consulting contexts. It is not directed at children under 16, and Truinorva GmbH does not knowingly process data from children through the Plugin (and as stated above, does not process data through the Plugin at all).

## Your rights under GDPR / DSGVO

Because the Plugin does not process personal data, the data subject rights under Articles 15–22 GDPR (access, rectification, erasure, restriction, portability, objection) have no Plugin-specific scope. For data Anthropic processes when you use Claude with the Plugin, exercise your rights with Anthropic directly via <https://privacy.claude.com>.

For data Truinorva GmbH processes through other channels (e.g. visiting truinorva.de, signing up for the newsletter, attending workshops), see our main privacy policy at <https://www.truinorva.de/privacy.html>.

## Changes to this policy

Material changes to this policy will be published at this URL and reflected in a new version of the Plugin. Non-material changes (typo corrections, link updates, formatting) may be made silently.

The version history of this document is publicly available in the Plugin repository.

## Scope and limitations

This policy covers only the Plugin as distributed through Anthropic's plugin directory and the official Truinorva repository. If you obtain a modified version of the Plugin from a third party, this policy does not necessarily apply — review the modified version's documentation.
